# Офлайн-распознавание PDF-заявок

Новый файл **`pdf_table_ocr.py`** заменяет старую логику "распознать всю
страницу текстом и парсить регулярками" на распознавание **по ячейкам
таблицы**: сначала находятся линии сетки таблицы (OpenCV), затем каждая
ячейка распознаётся Tesseract'ом отдельно. Это значительно надёжнее —
не путает колонки и не собирает "мусорные" ФИО из шапки письма.

Всё работает **полностью локально**, без интернета и без Claude API.

## Что нужно установить (один раз)

```
pip install pdf2image pytesseract opencv-python-headless numpy
```

Плюс на компьютере должны стоять:

1. **Poppler** (для pdf2image) — судя по вашему `gui.py`, уже установлен:
   `C:\Users\xofla\...\poppler-25.07.0\Library\bin`
2. **Tesseract OCR с русским языком** — судя по вашему `gui.py`, тоже
   установлен: `C:\Program Files\Tesseract-OCR\tesseract.exe`

Оба пути уже прописаны как значения по умолчанию в
`pdf_table_ocr.py` (`DEFAULT_TESSERACT_PATH`, `DEFAULT_POPPLER_PATH`).
Если у вас другой компьютер/пути — поменяйте их в начале файла один раз.

## Что изменилось

- **`pdf_table_ocr.py`** (новый файл) — основная логика распознавания таблиц.
- **`create_protocol.py`** — функция `extract_from_pdf()` теперь вызывает
  новый модуль вместо заглушки "введите вручную". Если в заявке несколько
  таблиц (например, отдельно 1и2 группа и 3 группа), скрипт в консоли
  предложит выбрать нужную или объединить все.
- **`gui.py`** — `extract_from_pdf_ocr()` переписан на новый модуль.
  Если таблиц несколько — появится окошко выбора нужной таблицы
  (или кнопка "Объединить все").

## Важно

- Тестировал структуру распознавания (поиск таблиц, строк, столбцов) на
  вашей реальной заявке — сетка находится точно, ячейки вырезаются
  ровно по границам. Сам текст в моей тестовой среде не проверял (там
  нет русского языка Tesseract) — проверьте на своём компьютере.
- Если распознавание где-то ошибается (нечёткий скан, необычный шрифт),
  это можно поправить прямо в таблице GUI перед генерацией протокола —
  автоматическое распознавание не обязано быть идеальным на 100%,
  достаточно, чтобы экономило время на ручном вводе.
