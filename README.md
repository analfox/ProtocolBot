# ProtocolBot - Создание протоколов об обучении

## Быстрый старт

1. Двойной клик на **Запуск.bat**
2. Или: `python gui.py`

## Как пользоваться

### Настройки (кнопка «⚙ Настройки»)
- Путь к заявкам — с этой папки открывается окно «Выбрать файл»
- Путь к готовым документам — с этой папки открываются окна сохранения
  протоколов, удостоверений и реестра
- Пустой путь или папки нет — окно откроется в папке программы
- Там же пути к Tesseract/Poppler для распознавания PDF. Всё хранится в config.json

### Шаг 1: Выберите файл
- Нажмите "Выбрать файл"
- Найдите Excel или Word файл со списком участников
- Поддерживаемые форматы: .xlsx, .xls, .docx, .doc

### Шаг 2: Заполните данные протокола
- Номер протокола (из журнала)
- Дата (по умолчанию - сегодняшняя)
- Группа (1, 2 или 3)
- Количество часов
- Учебная группа (для протокола Минтруда)
- № первого удостоверения (по журналу): у каждого удостоверения свой номер, +1 на каждое
  (человек с двумя группами получает два номера). Эти же номера ставятся в протокол
  и ведомость; если поле пустое — в протоколе остаётся прочерк
- Организация и ИНН организации

### Шаг 3: Введите допуски
- В таблице с участниками в колонке "Коды допусков" введите числа
- Формат: `10,12,15` или `10-15` или `1,10-13,20`
- Нажмите "Справка по допускам" для просмотра кодов

### Шаг 4: Сохраните
- Нажмите "Сгенерировать протокол"
- Выберите место сохранения
- Рядом автоматически создаётся второй протокол — проверки знаний ОТ для Минтруда
  (`Протокол_Минтруд_<номер>_<дата>.docx`, по шаблону `mintrud_protocol_template.docx`).
  Номер, дата, часы и учебная группа берутся из шага 2; рег. номер из реестра заполняется вручную.
  Приказ о комиссии меняется прямо в шаблоне (в Word), плейсхолдеры в {скобках} не трогать.
- Готово!

### Реестр для Минтруда
- Нажмите "Сформировать реестр" — заполнится `registry_template.xlsx`
  (копия `Шаблон_Реестр_ОТ.xlsx` из MintrudBot)
- Заполняются: организация и ИНН организации (поля шага 2), ФИО, СНИЛС, должность, программа
  («9. Безопасные методы и приемы выполнения работ на высоте»),
  результат «Удовлетворительно», дата и номер протокола из шага 2
- СНИЛС берётся из колонки «СНИЛС» заявки; поправить можно двойным кликом в таблице

## Коды допусков

### Группа 3 (ответственные лица) - коды 1-9
| Код | Описание |
|-----|----------|
| 1 | В качестве ответственного за организацию и безопасное проведение работ на высоте |
| 2 | В качестве ответственного исполнителя (производитель) работ |
| 3 | Ответственного за утверждение ППР на высоте |
| 4 | Ответственного за разработку и выполнение ППР на высоте |
| 5 | Ответственного за проведение обслуживания и периодический осмотр СИЗ |
| 6 | Ответственного лица, имеющего право выдавать наряд-допуск |
| 7 | Ответственного руководителя работ |
| 8 | Ответственного исполнителя (производитель) работ |
| 9 | Члена аттестационной комиссии организации |

| Код | Описание |

| 11 | Использование жестких и гибких анкерных линии |

| 13 | Применение грузоподъемных механизмов и устройств |
| 14 | Монтаж и демонтаж на высоте стальных и сборных несущих конструкций |
| 15 | Установка и монтаж на высоте деревянных конструкций |
| 16 | Выполнение кровельных и других работ на крышах зданий |
| 17 | Производство бетонных работ |

| 19 | Отделочные работы на высоте |
| 20 | Работа на антенно-мачтовых сооружениях |
| 21 | Работа на высоте в ограниченном пространстве |
