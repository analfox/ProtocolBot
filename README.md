# ProtocolBot - Создание протоколов об обучении

## Быстрый старт

1. Двойной клик на **Запуск.bat**
2. Или: `python gui.py`

## Как пользоваться

### Шаг 1: Выберите файл
- Нажмите "Выбрать файл"
- Найдите Excel или Word файл со списком участников
- Поддерживаемые форматы: .xlsx, .xls, .docx, .doc

### Шаг 2: Заполните данные протокола
- Номер протокола (из журнала)
- Дата (по умолчанию - сегодняшняя)
- Группа (1, 2 или 3)
- Количество часов

### Шаг 3: Введите допуски
- В таблице с участниками в колонке "Коды допусков" введите числа
- Формат: `10,12,15` или `10-15` или `1,10-13,20`
- Нажмите "Справка по допускам" для просмотра кодов

### Шаг 4: Сохраните
- Нажмите "Сгенерировать протокол"
- Выберите место сохранения
- Готово!

## Коды допусков

| Код | Описание |
|-----|----------|
| 1 | В качестве ответственного за организацию и безопасное проведение работ на высоте |
